# Chemical Safety Virtual Lab — Version 17

This folder is ready to upload to the GitHub repository used for the Canvas simulation.

## Files

- `index.html` — the interactive simulation
- `lab.png` — laboratory background image
- `logo.jpg` — Adelaide University logo used in the activity
- `acetone.pdf` — Acetone Safety Data Sheet
- `naoh.pdf` — Sodium Hydroxide Safety Data Sheet
- `ipa.pdf` — Isopropyl Alcohol (IPA) Safety Data Sheet

## Updating a file later

Keep the filenames the same when replacing an asset. For example, to update the IPA SDS, replace
`ipa.pdf` with the new PDF and commit the change to GitHub. The Canvas embed URL does not need to change.

## GitHub Pages

The site continues to use the repository root as the GitHub Pages source. Because the main file is
named `index.html`, the activity loads from the repository's GitHub Pages address.

## SOP files

- `heater-stirrer-sop.pdf` — Heater Stirrer SOP
- `sharps-glass-sop.pdf` — Sharps and Glass SOP

The SDS and SOP resource buttons open the documents in a new browser tab. The old duplicate SDS links and sidebar "Open SDS"/"Open SOP" buttons have been removed.

# Chemical Safety Virtual Lab — Final Version 17

This folder contains the complete GitHub Pages version of the ENGI1009 Virtual Lab 1 chemical safety inspection.

## Files

- `index.html` — interactive chemical safety inspection
- `lab.png` — laboratory background image
- `logo.jpg` — Adelaide University logo
- `acetone.pdf` — Acetone Safety Data Sheet
- `NaOH.pdf` — Sodium Hydroxide 40% Safety Data Sheet
- `IPA.pdf` — Isopropyl Alcohol (IPA) Safety Data Sheet
- `heater-stirrer-sop.pdf` — Heater Stirrer Safe Operating Procedure
- `sharps-glass-sop.pdf` — Sharps and Glass Safe Operating Procedure

## Simulation features

- 14 interactive safety-inspection hotspots
- live inspection progress and checklist
- final safety check and reset controls
- SDS resource buttons
- SOP resource buttons
- SDS and SOP documents open in a new browser tab
- Adelaide University branding

## Important filename note

GitHub Pages filenames are case-sensitive. Keep these filenames exactly as shown above, particularly:

- `NaOH.pdf`
- `IPA.pdf`

If a PDF is replaced later, keep the same filename so the links in `index.html` continue to work.

## Updating GitHub

Replace the relevant file in the repository, commit the change, and push to `main`. The GitHub Pages address and the Canvas iframe URL do not need to change when the filenames stay the same.

## Canvas

The simulation should continue to be embedded in Canvas using the GitHub Pages URL for the repository.
